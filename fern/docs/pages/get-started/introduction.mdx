The Habit Tracking API is a multi-tenant, OAuth 2.0-secured REST API for creating and analysing personal habits. Every route lives under `/v1` and returns JSON.

## Resources

- **Users** — the authenticated principal (`/users/me`).
- **Categories** — user-scoped grouping for habits.
- **Habits** — the trackable behavior; supports full CRUD.
- **Check-ins** — completion records for a habit.
- **Streaks** — computed consecutive-completion runs.
- **Reminders** — scheduled nudges attached to a habit.
- **Analytics** — aggregate summaries and per-habit trends.
