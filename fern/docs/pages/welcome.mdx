The Habit Tracking API is a multi-tenant, OAuth 2.0-secured REST API for creating and analyzing personal habits. Use it to model users, habits, check-ins, streaks, reminders, and analytics under a single `/v1` surface.

## Explore by task

- **[Users](/guides/users)** — manage the authenticated principal.
- **[Categories](/guides/categories)** — organize habits into user-scoped groups.
- **[Habits](/guides/habits)** — create and maintain the trackable behaviors.
- **[Check-ins](/guides/check-ins)** — record completions and build history.
- **[Streaks](/guides/streaks)** — surface consecutive-completion runs.
- **[Reminders](/guides/reminders)** — schedule nudges attached to a habit.
- **[Analytics](/guides/analytics)** — aggregate summaries and per-habit trends.
